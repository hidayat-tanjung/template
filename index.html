Panduan LinuxPloiter Recon Suite

Ringkasan fungsi, langkah penggunaan, dan batasan tiap alat.

Alur singkat: pastikan target termasuk scope yang diizinkan, pilih alat, isi target atau query, jalankan pencarian, lalu tinjau dan ekspor hasil. Tidak semua fitur memerlukan API key.
Data pengaturan disimpan di localStorage browser. File ekspor pengaturan dapat berisi API key, jadi simpan dengan aman. CORS proxy pihak ketiga dapat melihat request yang diteruskan.

🎨 Tampilan Baru v8.0

Header Desktop (2 Baris)

Baris pertama menampilkan logo dan nama LinuxPloiter di kiri, serta ikon komunitas, Rating, API Keys, dan bahasa di kanan. Baris kedua menampilkan dropdown tab, History, Theme, serta ekspor JSON/CSV dari kiri.

  • Baris 1: Brand di kiri; community, Rating, API Keys, dan Language rata kanan.
  • Baris 2: Dropdown semua tab, History, Theme, JSON, dan CSV rata kiri.
  • Dropdown tab dan drawer mobile dibuat otomatis dari daftar tab utama agar selalu sinkron.

Mobile Menu (Drawer)

Pada layar di bawah 900px, tombol header dan tab desktop digantikan tombol hamburger.

  • Klik tombol hamburger di kanan atas untuk membuka drawer dari sisi kiri.
  • NAVIGASI: semua 14 tab yang tersedia pada navigasi desktop.
  • TOOLS: API Keys & AI, History, Theme, Export JSON/CSV, dan Rating.
  • COMMUNITY: tautan komunitas; LANGUAGE: pilihan bahasa.
  • Tutup dengan tombol ✕, area gelap di luar drawer, tombol Escape, atau resize ke desktop.

API Key Manager

Buka ⚙️ API Keys & AI, pilih provider, masukkan API Key, lalu pilih Simpan atau Test. Beberapa key dari provider berbeda dapat disimpan, diuji, dan dihapus satu per satu. Custom provider mendukung Base URL dan Model.

AI keys tersimpan pada localStorage browser dan digunakan oleh Error Analyzer. Kredensial browser tidak dienkripsi; jangan gunakan perangkat bersama dan jangan membagikan ekspor settings yang berisi API keys.

Donasi

Form input nama, email, dan HackerOne telah dihapus. Tombol PayPal dan Bitcoin serta QR code donasi tersedia di panel profil.

🐧 Apa itu LinuxPloiter?

LinuxPloiter adalah workstation recon client-side — semua berjalan di browser kamu, tanpa server, tanpa tracking. Cocok untuk bug hunter, security researcher, dan pentester yang butuh tool ringan untuk reconnaissance awal.

Kami hadir untuk semua yang cinta teknologi, keamanan, dan AI — dengan tutorial yang gampang diikuti. Dari perintah Linux sampai strategi cyber defense, dari Bug Bounty sampai DevOps & otomasi AI.

🎯 Kenapa dibangun?

  • Tool recon simpel, cepat, dan bisa dipakai di mana saja — cukup buka browser.
  • Gratis & open — bukan pengganti Burp Suite / nuclei, tapi melengkapi workflow kamu.
  • Privasi nomor satu — semua data di localStorage, tidak ada yang dikirim ke server.
  • Belajar sambil praktik — setiap tool ada panduan singkat di tab Guide.
